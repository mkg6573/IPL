


# 🏏 IPL Analysis Dashboard (2008 - 2024)

This Streamlit web application provides an interactive analysis of the Indian Premier League (IPL) from 2008 to 2024. Users can explore various insights such as final winners, team performance, and much more through simple dropdown selections.

## 🔍 Features

- 📊 Visual analysis of IPL statistics from 2008 to 2024
- 🏆 Final winner selection and overall insights
- 🎯 User-friendly interface built with Streamlit


```bash
pip install streamlit pandas matplotlib
streamlit run app.py
```
